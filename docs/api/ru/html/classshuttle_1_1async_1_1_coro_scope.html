Подробное описание

Move-only lifetime token для дерева дочерних корутин.

Scope передаётся по значению в AsyncTask-корутину и хранится в coroutine frame. Создание child увеличивает счётчик родителя, а разрушение child frame уменьшает его. Родительский объект обязан оставаться живым, пока все его дочерние frame не завершились. LaunchOptions наследуются в перегрузках launch без явных параметров.

Immediate запускает тело при создании (до возврата фабрики), Async ставит задачу в явный executor, Lazy возвращает ещё не запущенную задачу. Ошибки создания/постановки возвращаются в AsyncTask. Внутренняя синхронизация использует атомики; копирование запрещено, перемещение scope допустимо только в рамках передачи его владения в coroutine frame.

Создаёт child с Immediate режимом; выполнение начинается в текущем потоке.

Выполнение корутины начинается синхронно в вызывающем контексте до первой точки приостановки.

Предупреждения
КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ ПО БЕЗОПАСНОСТИ: Использовать оператор co_await внутри этой задачи разрешается строго в рамках одного и того же потока (например, совместно с ThreadPinnedExecutor / OneThreadExecutor). Ни в коем случае не допускайте миграции контекста выполнения на другие потоки или пулы потоков внутри Immediate-задач. Смена потока возобновления нарушит иерархию Structured Concurrency и приведёт к неопределённому поведению (UB).

Возвращает
AsyncTask результата либо ошибка создания.
