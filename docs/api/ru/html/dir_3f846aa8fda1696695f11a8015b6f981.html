Подробное описание

Диаграммы PlantUML на русском языке

Все файлы .puml в этой директории содержат подписи только на русском. Английские версии с такими же именами находятся в ../en/.

Генерация PNG

Установите Java и PlantUML, затем настройте проект, указав путь к JAR-файлу PlantUML:

cmake -S . -B build -DPLANTUML_JAR="C:\tools\plantuml.jar"
cmake --build build --target uml_png

Если CMake не обнаружил Java автоматически, укажите также -DJAVA_EXECUTABLE="C:\путь\к\java.exe". Вместо JAR можно использовать исполняемый файл PlantUML: -DPLANTUML_EXECUTABLE="C:\путь\к\plantuml.exe".

PNG создаются в build/uml/ru/, а английские PNG — в build/uml/en/. Исходники диаграмм имеют кодировку UTF-8.
