Подробное описание

Многопоточный executor с локальными deque и work-stealing.

Создаётся фабрикой create(), которая запускает worker-ы. Внешние отправители используют общую входящую очередь; отправка из worker-а добавляет работу в его локальную очередь. Деструктор останавливает и присоединяет потоки. Все coroutine handles не владеющие: frame должны сохраняться вызывающей стороной до завершения задачи; отправители не должны конкурентно обращаться к executor-у во время его разрушения, и пул нельзя разрушать из собственного worker-а. Callback перемещается внутрь пула.
