Подробное описание

template<typename T>
class shuttle::async::AsyncSharedState< T >

Внутреннее общее состояние producer/consumer асинхронной задачи.

Создаётся только AsyncStateFactory внутри allocator-aware блока и имеет intrusive reference counting. AsyncPromise, AsyncFuture и их awaiter-ы держат отдельные ссылки. Результат T размещается inline посредством placement new, а пользовательский allocator выделяет единый блок AllocationBlock; последний release вызывает сохранённый deleter для разрушения блока и возврата памяти allocator-у.

Разрешено единственное значение и единственный consumer. Для void value storage не содержит T. Нельзя уничтожать состояние до завершения всех операций, которые используют его внутренний указатель.

Параметры шаблона
TТип результата; может быть void.
