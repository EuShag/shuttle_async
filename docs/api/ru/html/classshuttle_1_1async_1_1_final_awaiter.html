Подробное описание

Финализирует AsyncTask и передаёт управление scope/исполнителю.

Перед уничтожением frame временно удерживает shared state и публикует завершение. Callback-ы состояния передаются как type-erased функции, чтобы awaiter не зависел от параметра шаблона AsyncTask.
