Подробное описание

template<typename T = void>
struct shuttle::async::AsyncTask< T >::promise_type

Coroutine promise, связывающий frame, scope и shared state.

State выделяется отдельно с MiAllocator. При неудаче аллокации get_return_object возвращает ошибочную AsyncTask, а тело не исполняется.
