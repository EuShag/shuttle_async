Подробное описание

Настройки запуска дочерней задачи.

Указатель исполнителя не владеющий: он должен оставаться действительным в течение постановки и исполнения задачи. Для Immediate/Lazy он не используется самим запуском; для Async требуется ненулевой указатель.
