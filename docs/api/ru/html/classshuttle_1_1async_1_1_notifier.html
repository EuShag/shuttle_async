Подробное описание

Потокобезопасное уведомление с ожиданием предиката через atomic wait.

Уведомление не хранит число событий: вызывающая сторона должна проверять собственное атомарное состояние в predicate. Предикат может вызываться несколько раз; вызовы notify увеличивают поколение и пробуждают waiter-ов.
