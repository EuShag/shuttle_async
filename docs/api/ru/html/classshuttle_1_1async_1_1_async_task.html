Подробное описание

template<typename T = void>
class shuttle::async::AsyncTask< T >

Move-only результат корутинной операции.

AsyncTask владеет coroutine handle и Future, но его деструктор при уничтожении ещё принадлежащего ему handle только выставляет cancellation flag; это кооперативная отмена, а не синхронное уничтожение работающего frame. При ожидании handle передаётся awaiter-у, а frame уничтожается через FinalAwaiter. Запуск бывает Immediate (scope выполняет при создании), Async (scope ставит в исполнитель) и Lazy (ожидает start/co_await).

Отмена наблюдается через cancellationPoint и awaiter-ы; произвольное тело корутины автоматически не прерывается. Ошибки создания/запуска доступны как Error/Status, а успешное ожидание возвращает AsyncResult<T>.

Параметры шаблона
TТип возвращаемого значения; по умолчанию void.

Выставляет отмену при разрушении пока принадлежащей задаче.

Если задача содержит ошибку, frame уничтожается немедленно; иначе устанавливается только shared cancellation flag. Исполняющийся frame продолжает жить до собственной финализации; frame явно не уничтожается этим деструктором.

Запускает задачу при необходимости и готовит ожидание на executor-е.

Аргументы
explicitExecutorНе владеющий executor для возобновления waiter-а; nullptr допустим только если результат уже готов.
Возвращает
Awaitable с собственной ссылкой на state.
Заметки
Для старта используется pinned executor текущего TLS-контекста; explicitExecutor применяется для возврата ожидающего caller-а.
При отказе старта await-path может возобновить coroutine на текущем потоке.
Thread safety: не синхронизирует одновременное перемещение/ожидание одного объекта.
Передаваемый frame handle снимается с AsyncTask, чтобы деструктор не выставлял ложную отмену после передачи ожидателю.
