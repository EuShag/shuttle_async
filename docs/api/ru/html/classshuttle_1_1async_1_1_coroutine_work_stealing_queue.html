Подробное описание

template<size_t LogSize = 12>
class shuttle::async::CoroutineWorkStealingQueue< LogSize >

Ограниченная Chase–Lev deque для coroutine handles.

Единственный владелец deque вызывает try_push/pop; другие потоки могут конкурентно вызывать steal. Очередь не владеет coroutine frame, а лишь передаёт handle. Емкость фиксирована, при заполнении push возвращает false.

Параметры шаблона
LogSizeДвоичный логарифм ёмкости; должен быть в диапазоне [1, 30).
