Подробное описание

template<typename T>
class shuttle::async::AsyncPromise< T >

Move-only producer-владелец общего состояния.

Promise держит одну intrusive-ссылку. Уничтожение незавершённого promise вызывает abandon(): отменяет состояние и сигнализирует зарегистрированного waiter-а. Значение размещается placement new в динамическом allocator-owned блоке; ровно один вызов setValue/storeValue допустим.

Параметры шаблона
TТип результата или void.
