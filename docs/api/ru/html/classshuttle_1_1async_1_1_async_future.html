Подробное описание

template<typename T>
class shuttle::async::AsyncFuture< T >

Move-only consumer-владелец общего состояния.

Future владеет одной intrusive-ссылкой. Подготовленные awaitable и awaiter удерживают собственные ссылки, поэтому они могут пережить перемещение или уничтожение Future. Один результат можно потребить только одним awaiter-ом. Пустой объект безопасно перемещать/уничтожать; его проверка ожидания трактуется как отменённый результат.

Параметры шаблона
TТип результата или void.
