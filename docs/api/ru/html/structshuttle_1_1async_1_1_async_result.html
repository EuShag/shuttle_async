Подробное описание

template<typename T>
struct shuttle::async::AsyncResult< T >

Результат ожидания асинхронной операции.

Значение возвращается перемещением, а отмена представлена отдельным флагом; ошибки запуска/исполнителя этим типом не кодируются. При отмене значение не следует использовать. Тип не синхронизирует доступ и сам по себе не обеспечивает потокобезопасность.
