Подробное описание

template<typename T>
struct shuttle::async::AsyncStatePair< T >

Перемещаемая пара владельцев одного AsyncSharedState.

Promise и Future получают по одной начальной ссылке на общее состояние. Пара и оба её элемента move-only.

Параметры шаблона
TТип результата или void.
