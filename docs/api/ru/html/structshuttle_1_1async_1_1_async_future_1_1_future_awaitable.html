Подробное описание

template<typename T>
struct shuttle::async::AsyncFuture< T >::FutureAwaitable

Объект awaitable, позволяющий одноразово получить FutureAwaiter.

Удерживает собственную ссылку на state до разрушения; только один awaiter может быть получен из awaitable/Future для данного состояния.
