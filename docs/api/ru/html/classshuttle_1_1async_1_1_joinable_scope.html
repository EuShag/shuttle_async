Подробное описание

Корневой scope, деструктор которого синхронно дожидается всех детей.

joinAll() блокирует вызывающий OS-поток при наличии активных задач. Для launch(options, ...) возвращается BlockingTask; остальные overload-ы делегируют базовому CoroScope и возвращают AsyncTask.

◆ joinAll()

void shuttle::async::JoinableScope::joinAll ( )
inline

Дожидается уничтожения всех дочерних coroutine frame.

Устанавливает TLS BlockingExecutor на время ожидания. Метод блокирует текущий поток; вызов из дочернего worker-потока этого же scope может привести к deadlock и не является поддерживаемым шаблоном использования.

Создаёт задачу в Immediate режиме.

Выполнение корутины начинается синхронно в вызывающем контексте до первой точки приостановки.

Предупреждения
КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ ПО БЕЗОПАСНОСТИ: Использовать оператор co_await внутри этой задачи разрешается строго в рамках одного и того же потока (например, совместно с ThreadPinnedExecutor / OneThreadExecutor). Ни в коем случае не допускайте миграции контекста выполнения на другие потоки или пулы потоков внутри Immediate-задач. Смена потока возобновления нарушит иерархию Structured Concurrency и приведёт к неопределённому поведению (UB).
