Подробное описание

template<typename T = void>
struct shuttle::async::AsyncTask< T >::promise_type::SwitchExecutorAwaiter

Awaiter переключения текущей coroutine на заданный executor.

Всегда проходит через await_suspend. При уже выставленной отмене, nullptr executor-е или ошибке execute() продолжает текущий handle на текущем потоке; при успехе возвращает dispatcher текущего потока.
