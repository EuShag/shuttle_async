Detailed Description

template<typename T>
class shuttle::async::BlockingTask< T >

AsyncTask wrapper whose get() blocks the calling OS thread.

Used by the JoinableScope::launch overload with explicit options. start() remains asynchronous; get() installs a BlockingExecutor in the current thread's TLS and waits for shared-state signaling. For non-void T, get() returns an rvalue reference to the value in the state, not an owning value. This interface does not check cancellation or payload presence before extracting the result.

decltype(auto) shuttle::async::BlockingTask< T >::get ( )
inline

Blocks the current OS thread until the shared state is signaled.

Returns
void for T == void; otherwise, an rvalue reference to the stored T.
Precondition
The task is valid and a consumer is available; an executor must be configured for asynchronous completion.
Warning
For non-void tasks, the reference is non-owning and becomes invalid when the shared state is destroyed. Do not extract a result from a cancelled task with no value.
