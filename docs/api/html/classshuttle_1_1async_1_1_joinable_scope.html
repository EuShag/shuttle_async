Detailed Description

Root scope whose destructor synchronously waits for all children.

joinAll() blocks the calling OS thread while tasks are active. The launch(options, ...) overload returns BlockingTask; other overloads delegate to the base CoroScope and return AsyncTask.

Waits for all child coroutine frames to be destroyed.

Installs a TLS BlockingExecutor while waiting. This method blocks the current thread; calling it from a child worker thread of the same scope may deadlock and is not a supported usage pattern.

Creates a task in Immediate mode.

Coroutine execution starts synchronously in the calling context until the first suspension point.

Warning
CRITICAL SAFETY WARNING: Using the co_await operator inside this task is allowed strictly within the same thread context (e.g., in conjunction with a ThreadPinnedExecutor / OneThreadExecutor). Thread migration to other threads or thread pools inside an Immediate task is strictly prohibited. Changing the execution context to a different thread will break Structured Concurrency invariants and lead to undefined behavior (UB).
