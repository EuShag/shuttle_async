Detailed Description

Executor with a single worker thread and a queue of coroutine handles.

create() creates an instance and starts its worker. execute() enqueues tasks; the object is neither copyable nor movable. Destruction initiates shutdown and joins the worker, so the executor must outlive every coroutine that may use it. Destroying the executor on its own worker thread is forbidden: the implementation calls terminate.
