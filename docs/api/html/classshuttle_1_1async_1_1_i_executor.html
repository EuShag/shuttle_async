Detailed Description

Interface for enqueueing coroutine handles for execution.

The implementation determines the thread and time at which resumption occurs. The supplied handle remains non-owning: the caller is responsible for the frame's lifetime. If enqueueing fails, the coroutine must not be considered transferred to the executor.
