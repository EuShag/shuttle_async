Detailed Description

template<typename T = void>
struct shuttle::async::AsyncTask< T >::promise_type::SwitchExecutorAwaiter

Awaiter that switches the current coroutine to a specified executor.

Always goes through await_suspend. If cancellation is already set, the executor is null, or execute() fails, it continues the current handle on the current thread; on success, it returns the current thread's dispatcher.
