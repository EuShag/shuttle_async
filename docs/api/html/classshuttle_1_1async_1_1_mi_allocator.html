Detailed Description

template<typename T>
class shuttle::async::MiAllocator< T >

Stateless allocator for objects of type T, based on mimalloc.

Allocation is noexcept and returns nullptr on failure (unlike a standard allocator, which typically throws bad_alloc). Instances are interchangeable when deallocating memory.
