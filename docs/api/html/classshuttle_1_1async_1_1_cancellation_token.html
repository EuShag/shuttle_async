Detailed Description

template<typename T>
class shuttle::async::CancellationToken< T >

Move-only representation of a cancelled task.

Owns a moved AsyncTask and awaits its result exactly once. Cancellation is cooperative; this token's awaiter forcibly sets isCancelled in AsyncResult, regardless of the producer's value.

Template Parameters
TResult type of the wrapped task.
