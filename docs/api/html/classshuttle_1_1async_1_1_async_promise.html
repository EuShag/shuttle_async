Detailed Description

template<typename T>
class shuttle::async::AsyncPromise< T >

Move-only producer owner of shared state.

The promise holds one intrusive reference. Destroying an incomplete promise calls abandon(), cancelling the state and signaling its registered waiter. The value is placement-constructed in a dynamically allocated allocator-owned block; setValue/storeValue may be called exactly once.

Template Parameters
TResult type or void.
