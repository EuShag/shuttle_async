Detailed Description

Move-only lifetime token for a tree of child coroutines.

A scope is passed by value into an AsyncTask coroutine and stored in its frame. Creating a child increments the parent's counter; destroying the child frame decrements it. The parent object must remain alive until all child frames complete. LaunchOptions are inherited by launch overloads without explicit options.

Immediate starts the body during creation (before the factory returns), Async enqueues the task on an explicit executor, and Lazy returns a task that has not yet started. Creation/enqueue errors are returned in AsyncTask. Internal synchronization uses atomics; copying is disabled, and moving a scope is allowed only when transferring its ownership into a coroutine frame.

◆ m_childCount

std::atomic<uint64_t> shuttle::async::CoroScope::m_childCount { 0 }
private

Atomic synchronization state for tracking child frames.

Completion Invariant: The DEATH_SIGNAL flag is set by the joiner exactly once. The lower bits function as a reference counter for active child frames. The last child coroutine to observe the final transition (DEATH_SIGNAL + 1) assumes responsibility for waking the registered joiner.
