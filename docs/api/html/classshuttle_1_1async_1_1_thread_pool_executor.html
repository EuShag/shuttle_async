Detailed Description

Multithreaded executor with local deques and work stealing.

Created by the create() factory, which starts the workers. External submitters use the shared incoming queue; submissions from a worker go to its local queue. Destruction stops and joins the threads. All coroutine handles are non-owning: frames must remain alive under the caller's ownership until task completion. Submitters must not access the executor concurrently with its destruction, and the pool must not be destroyed by one of its own workers. The callback is moved into the pool.
