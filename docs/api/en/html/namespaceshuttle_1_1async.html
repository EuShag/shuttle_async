◆ AsyncTaskState

enum class shuttle::async::AsyncTaskState : uint32_t
strong

Lifecycle phases of a task's shared state.

Transitions are atomic: Pending may transition to Suspended or Signaled, and Suspended may transition to Signaled. Repeated completion does not signal a waiter more than once.

Enumerator
Pending 

State has been created; completion has not yet been published.

Suspended 

The single waiting coroutine handle has been registered.

Signaled 

Completion or cancellation has been published.

◆ Error

enum class shuttle::async::Error
strong

Errors that occur while creating, enqueuing, and executing asynchronous tasks.

Errors are carried as std::unexpected in Result/Status; they are distinct from normal cancellation, which is represented by AsyncResult.

Enumerator
allocation_failure 

Failed to allocate memory for an object or queue.

invalid_worker_count 

A zero or otherwise invalid number of worker threads was provided.

worker_start_failed 

Failed to create an executor thread.

invalid_coroutine_handle 

An empty or invalid coroutine handle was provided.

executor_stopped 

The executor has stopped and no longer accepts work.

queue_enqueue_failed 

The executor queue rejected a task during enqueue.

executor_unavailable 

No executor was found for asynchronous launch or awaiting.

◆ LaunchMode

enum class shuttle::async::LaunchMode
strong

Launch mode for a child coroutine created through CoroScope.

Enumerator
Immediate 

Run the coroutine immediately on the current thread.

Async

Lazy 

Return the created coroutine without starting it; it is started later.
