Detailed Description

template<typename T>
class shuttle::async::AsyncFuture< T >

Move-only consumer owner of shared state.

The future owns one intrusive reference. Prepared awaitables and awaiters hold their own references and can therefore outlive a moved-from or destroyed future. Only one awaiter may consume a result. An empty object can be moved or destroyed safely; awaiting it is treated as a cancelled result.
