Detailed Description

template<typename T = void>
struct shuttle::async::AsyncTask< T >::promise_type

Coroutine promise that connects the frame, scope, and shared state.

State is allocated separately using MiAllocator. If allocation fails, get_return_object returns an errored AsyncTask and the body is not run.
