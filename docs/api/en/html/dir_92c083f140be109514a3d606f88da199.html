Detailed Description

English PlantUML diagrams

Each .puml source in this directory contains English labels only. Russian sources with matching filenames are in ../ru/.

Render PNG

Install Java and PlantUML, then configure the project with the path to the PlantUML JAR:

cmake -S . -B build -DPLANTUML_JAR="C:\tools\plantuml.jar"
cmake --build build --target uml_png

If CMake does not find Java automatically, also pass -DJAVA_EXECUTABLE="C:\path\to\java.exe". A PlantUML CLI executable can be used instead with -DPLANTUML_EXECUTABLE="C:\path\to\plantuml.exe".

PNG output is generated under build/uml/en/; Russian output is under build/uml/ru/. Diagram sources are UTF-8.
