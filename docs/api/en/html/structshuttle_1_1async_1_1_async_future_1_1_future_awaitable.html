Detailed Description

template<typename T>
struct shuttle::async::AsyncFuture< T >::FutureAwaitable

Awaitable object that provides one-time access to a FutureAwaiter.

Holds its own reference to the state until destruction; only one awaiter may be obtained from the awaitable/Future for this state.
