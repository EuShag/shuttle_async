Detailed Description

template<typename T>
class shuttle::async::AsyncSharedState< T >

Internal shared producer/consumer state for an asynchronous task.

Created only by AsyncStateFactory inside an allocator-aware block, this state uses intrusive reference counting. AsyncPromise, AsyncFuture, and their awaiters each hold separate references. The result T is stored inline using placement new; the user allocator allocates one AllocationBlock. The final release invokes the saved deleter to destroy the block and return its memory to the allocator.

Exactly one value and one consumer are allowed. For void, the value storage contains no T. Do not destroy the state while any operation still uses its internal pointer.
