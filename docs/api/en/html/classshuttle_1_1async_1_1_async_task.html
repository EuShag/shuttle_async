Detailed Description

template<typename T = void>
class shuttle::async::AsyncTask< T >

Move-only result of a coroutine operation.

AsyncTask owns a coroutine handle and a Future. When it is destroyed while it still owns the handle, its destructor only sets the cancellation flag: this is cooperative cancellation, not synchronous destruction of a running frame. When awaited, the handle is transferred to the awaiter, and the frame is destroyed by FinalAwaiter. Launch modes are Immediate (the scope runs the body during creation), Async (the scope submits it to an executor), and Lazy (the task waits for start/co_await).

Cancellation is observed through cancellationPoint and awaiters; an arbitrary coroutine body is not interrupted automatically. Creation and launch errors are available as Error/Status, and successful awaiting returns AsyncResult<T>.
