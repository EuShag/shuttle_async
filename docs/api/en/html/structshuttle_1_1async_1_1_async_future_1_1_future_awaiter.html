Detailed Description

template<typename T>
struct shuttle::async::AsyncFuture< T >::FutureAwaiter

Awaiter that registers a coroutine as a state waiter.

Holds its own reference to the state. The executor and cancellation flag are non-owning pointers and must remain alive throughout the wait.
